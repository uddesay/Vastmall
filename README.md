# Vastmall

**Explore. Shop. Delight.** — a multi-vendor online marketplace with a Flipkart-style storefront: customer website + Android app, seller panel, rider (delivery partner) app, admin panel and API, all from one codebase.

Built from the Sureshot / Varnixo codebase (itself derived from RozShop). Production notes: [PRODUCTION.md](PRODUCTION.md).

## What's in it

| Who | Where | What they can do |
|---|---|---|
| **Customers** | `/` and the Android app | Blue-header storefront with a round-image category strip (15 departments), hero carousel, Deals of the Day, "Best of …" rows, Grocery section (`/grocery`), store search (`/stores`, `/store/:slug`), search, wishlist, **Add to cart** and **Buy now** (checks out that one item without touching the cart), cash-on-delivery checkout, order tracking |
| **Sellers** | `/seller` | Dashboard, add/edit products with photos, variants, prices and stock, submit for approval, pack orders |
| **Delivery partners** | `/rider` | Jobs with pickup/drop, directions, pick-up and delivery with COD confirmation (accounts created by admin; not advertised to customers) |
| **Vastmall team** | `/login` | RozShop-style admin: dashboard, products, orders, vendors, payouts, CMS, **Delivery → Dispatch / Delivery partners** |

**Departments:** Grocery, Electronics, Mobiles, Watches, Sunglasses, Men's Fashion, Women's Fashion, Bags & Footwear, Shoes, Jewellery, Car & Bike Accessories, Pet Store, Beauty, Kitchen Accessories, Toys — [backend/db/catalog-structure.js](backend/db/catalog-structure.js). Admins can add or hide categories under Catalog → Categories.

**Look:** the storefront follows the familiar Indian marketplace pattern (blue `#2874f0` header, white section cards, green rating badges, orange *Add to cart* and deep-orange *Buy now*). Styling lives in [web/src/store/fk.css](web/src/store/fk.css), layered over `vastmall.css` and `ss.css`. The logo is a **placeholder** generated by `python scripts/make-brand.py` — replace it when the client supplies one.

**Contact number:** not provided. Set it in [web/src/store/brand.ts](web/src/store/brand.ts) (`number = '91XXXXXXXXXX'`) and Call/WhatsApp links appear automatically.

## Requirements

Windows 10/11, Node.js 20+, PostgreSQL 14+ (tested on 16); optional Redis/Elasticsearch; for the app, Android Studio (JDK 21 + SDK 36).

## First-time setup

```powershell
cd D:\Vastmall
npm run install:all
$env:PG_ADMIN_USER = "postgres"
$env:PG_ADMIN_PASSWORD = "<your PostgreSQL superuser password>"
npm run setup                    # creates backend/.env, DB vastmall_dev, migrates, seeds
Remove-Item Env:PG_ADMIN_PASSWORD
npm run dev                      # API 4400 + web 5573
```

`npm run stop` stops both.

> **This machine:** development uses a private PostgreSQL in `.runtime/pgdata` on **port 5699** (`backend/.env` → `DB_PORT=5699`; password in `.runtime/pg-superuser.txt`, git-ignored). After a reboot:
> `& "C:\Program Files\PostgreSQL\16\bin\pg_ctl.exe" -D .runtime\pgdata -o "-p 5699 -c listen_addresses=localhost" -l .runtime\postgres.log start`

## Android app

The app is the storefront wrapped with Capacitor (`com.vastmall.app`).

```powershell
cd web
copy .env.app.example .env.app       # VITE_API_BASE_URL (absolute)
$env:VASTMALL_DEV_API = "1"          # only for a plain-http dev API (emulator: http://10.0.2.2:4400)
npm run app:apk                      # -> web/android-build/vastmall-debug.apk
```

For the Play Store, point `VITE_API_BASE_URL` at a live **https** API, unset `VASTMALL_DEV_API`, add `https://localhost` to the API's `CORS_ORIGINS`, and build a signed bundle in Android Studio.
